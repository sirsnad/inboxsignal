# Mockups

Exported from the design canvas. Open each in a browser to see layout and styling; the
`{{ }}` placeholders and `<sc-if>` / `<sc-for>` tags are template syntax from the design
tool and will not render as-is. The `<script type="text/x-dc">` block at the bottom of
Desktop.html and Desktop2.html holds the state machine for the interactive prototype:
read it for the exact section transitions, copy for toasts and logs, and the command list.

- Main.html      phone home screen (Today)
- Lane.html      phone lane screen (Homes)
- Senders.html   phone sender rules screen
- Desktop.html   desktop Today + reading pane, with the reply flow and Needs you actions
- Desktop2.html  same, plus Cmd+K palette, single-key actions, tier marks, New senders card,
                 Reads shelf, Notebook. This is the target for desktop.
